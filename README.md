# Chente Shop - sitio de práctica

Sitio estático con varias páginas HTML, CSS, JavaScript e ilustraciones SVG.

## Publicación en GitHub Pages

1. Crear un repositorio público nuevo en GitHub.
2. En CMD, entrar a la carpeta `mi-tienda-practica`.
3. Ejecutar `git init`, `git add .`, `git commit -m "Primera version"`, `git branch -M main`.
4. Vincular el repositorio con `git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git`.
5. Ejecutar `git push -u origin main` y activar Pages desde Settings > Pages > Deploy from a branch > main > /(root).

Este sitio no procesa pagos, no recopila contraseñas ni envía información a servicios externos.
